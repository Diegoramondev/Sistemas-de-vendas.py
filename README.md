# Sistema de Vendas em Python

Este projeto é um sistema de vendas simples, desenvolvido em Python como parte de uma atividade prática de aprendizado. O programa simula a venda de um produto, calcula o valor total e oferece diferentes métodos de pagamento com tratamento de erros e uma interface interativa no terminal.

## Funcionalidades

- Entrada de dados do usuário (nome do produto, preço unitário e quantidade);
- Cálculo automático do valor total da venda;
- Escolha entre três métodos de pagamento: dinheiro, pix ou cartão;
- Tratamento de erros para entradas inválidas (como letras no lugar de números);
- Interface simples e amigável para uso no terminal;
- Mensagens claras para orientar o usuário.

## Como usar

1. Abra o IDLE Python ou outro editor de sua preferência.
2. Copie o conteúdo do arquivo `atividade_final.py` para seu ambiente.
3. Execute o programa.
4. Siga as instruções exibidas no terminal para realizar uma venda.

## Requisitos

- Python 3.x instalado em seu computador.
